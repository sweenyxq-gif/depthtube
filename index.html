Features

Built past the stock patch set

The Morphe patches do the heavy lifting. The DepthTube finish adds a self-healing stream engine and full in-app branding.

No ads, anywhere

Video, banner, and audio ads removed in both apps — including the ones baked into music playback.

True background play

Screen off, app minimized, picture-in-picture — playback never stops. No Premium required.

Self-healing streams

Seven playback clients chained behind your pick. If one is rejected, the next takes over automatically — and the winner is remembered first for the next video. No settings diving, no “could not fetch streams”.

SponsorBlock built in

Sponsors, intros, outros, and self-promo are skipped the moment they start. Community-powered, fully configurable.

Dislike counts are back

Return YouTube Dislike restores real dislike numbers on every video, in both apps.

Real downloads

Save videos and tracks for offline. Music gets exclusive-audio playback and DRC-free sound while it’s at it.

Pure-black theme

A true #000 dark theme baked in — OLED-friendly, easier on the eyes and the battery. Shorts clutter trimmed by default.

No root, safe sign-in

Installs beside the stock apps under its own package names. Sign-in runs through MicroG-RE — your Google password never touches the modded app.

FAQ

When something looks off

“There is a problem with the app file” while installing

That’s a corrupted download, not a bad build. Delete every downloaded copy, re-download from this page, and check the file size matches the card exactly (104,477,530 bytes for DepthTube, 75,995,036 for Music) before installing. A file that’s bigger or smaller than listed will always fail to parse.

A video says “Could not fetch any client streams”

Update to the latest build above — since v1.2 the app retries seven playback clients automatically and remembers the winner. If it still appears on the newest build, every client was rejected, which points at the network or account layer: try switching Wi-Fi/mobile data and turn off VPN or private DNS.

How do updates work?

Every DepthTube build is signed with the same key, so a new version installs straight over the old one — settings, sign-in, and downloads carry over. One exception: v1.4 / Music v1.1 changed the package names to app.depthtube.*, so those two are fresh installs (sign in once more, then uninstall the old app.morphe.* copies). Everything after installs in place as usual. Never install a DepthTube APK from anywhere else; a different signature means a different app.

Which Android versions are supported?

DepthTube needs Android 10 or newer; DepthTube Music runs on Android 8+. Both builds are arm64-only, which covers effectively every phone from the last several years — including Android 17 devices.

Is sign-in safe?

The apps never see your password. Sign-in is handled by MicroG-RE, an open-source reimplementation of Google Play services, and the apps run under their own package names (app.depthtube.*) beside the stock apps — nothing is overwritten and no root is involved.

Who builds this?

DepthTube is a personal project by dj, built on the open-source Morphe patch set. The patches themselves are GPL-licensed; attribution ships inside each app, as the license requires.
